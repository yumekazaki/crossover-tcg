# Standard terminology

Version1.0.0. The master rulebook prevails. No subtype grants inherent abilities.

| Term | Meaning |
|---|---|
| Add to Party | Place Character into empty Party Zone. Standard action once/own turn; explicit effect Adds are additional. |
| Main Character | Character in Center, with13000 bonus maximum/current HP. |
| Party Member / Party Character | Character in one of six Party Zones. |
| Chain Attack / Attack Chain | One initiator, declared paid extra attackers, one original target and combined damage calculation. |
| Allied Guard | Additional eligible Party Member included in damage split;2 Momentum each before responses. |
| Menu | Open sequence, then entire backward resolution after two consecutive passes. No insertion during resolution. |
| Menu Select | One pending activated/triggered effect or rule action. Rule actions are not Ability cards. |
| Special | Character ability: Active, Triggered or Passive. Usually free. |
| Trigger | Collected event-based ability; costs paid at resolution. Departure does not erase collected identity. |
| Delayed effect | Established effect waiting for printed timing; does not require source unless explicit. |
| Activation cost | Paid upfront, never refunded on failure/negation; includes printed discard/HP/return costs. |
| Activation Negation | Prevents successful activation; costs and usages remain consumed. |
| Effect Negation | Activation occurred; specified effects prevented. Does not detach Equipment. |
| Protection | Literal printed scope and duration only. Layers coexist. |
| Suspension | Suppression while original duration continues; no new effect on resumption. |
| Bearer / host | Attached Character. Activated effect remembers target instance; passive requires source attached. |
| Compatible | All AND requirements plus an alternative in every OR group. Checked at attachment. |
| Printed | Registered unmodified value, tag or text. |
| Actual maximum HP | Printed HP plus active Center/gear/other modifiers. |
| Full HP | Current HP equals actual maximum. |
| Damaged / wounded | Current HP below actual maximum. |
| Below half | Strict currentHP < maximumHP/2; 'half or less' includes equality. |
| Heal / restore HP | Increase current HP up to actual maximum; does not revive. |
| Separate damage | Effect damage independent of combat division; no player life loss/defeat Momentum. |
| Reduction / prevention | After split unless explicitly global; never makes damage negative. |
| Redirection | Moves assignment, not original attack target. No repeat redirection unless explicit. |
| Defeat | HP reaches zero after damage finalization; different from direct send/return. |
| Continue? | Public discard/graveyard zone; movement itself does not cause life loss. |
| Party Swap | Own Main,6 Momentum, up to2 nontransformed Party returns; special gear refund. |
| Transformed | Form Character entered from arsenal; exact base, locked zone, nondamage removal protection. |
| Base Reserve | Second existing registered exact base copy for transformed Main restoration. |
| Persona Manifestation | Ability subtype; resolve and discard, no persistent Persona zone. |
| Fusion State | Interlink's linked temporary pair; no implied Transformed rules. |
| Once per turn per card name | Shared across player's copies/instances, including negated activations; resets each turn. |
| Equipment once per turn | Each physical copy and individual ability; no reset on transfer/removal/reattachment. |
| One Finisher per combat | Printed launch restriction, each player separately; independent of6-copy deck cap. |
| Another | Excludes source. |
| Allied / opposing | Controlled by you / opponent. Registered ownership never changes. |
| Target / choose | Specific object selection on activation/collection; 'all/each' is not individual targeting. |
| This turn | Expires current End Phase, does not automatically cover enemy Battle. |

No generic tapping, retaliation, elemental weakness, stun, Break, summon token or hidden third deck exists in this edition. Species, affiliations, disciplines and form categories remain separately classified.
